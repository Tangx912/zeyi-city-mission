# 张泽一 2026 暑假城市任务局 PWA 设计规格

## 背景

本项目属于“宝宝养育”和“AI 尝试”两类工作：把 Obsidian 中《张泽一 2026 暑假城市任务局教案》的 PBL 暑假安排，做成一个明天即可开始使用的手机网页/PWA 原型。

用户明确选择：

- 运行形态：手机网页/PWA 原型，先不做微信小程序。
- 信息架构：`今日任务台 + 项目任务包`。
- MVP 方案：引导任务版。
- 视觉方向：城市地图冒险风格，不做打卡文件感；底部菜单切换分类；首页以任务为主。

## 设计目标

第一版要解决三件事：

1. 每天打开后，能快速知道今天可以做什么。
2. 运动、PBL、书面作业、素材成果能分开记录，互不混乱。
3. 暑假结束能导出作品册草稿、素材清单和数据备份。

第一版成功标准：

- 用户明天可以在手机浏览器里开始记录。
- 完成一次“今日任务 + 运动 + 书面作业 + PBL 留痕”的流程不超过 3 分钟。
- 任务包不强制按教案周次执行，允许穿插完成。
- 导出内容足够用户后续自行整理成文本或作品册。

## 非目标

第一版不做：

- 微信小程序发布。
- 登录和账号系统。
- 云同步和多人协作。
- 精美 PDF 自动排版。
- 复杂权限、分享、评论。
- AI 自动生成完整作品册文案。

这些可以在第一版跑通后再升级。

## 产品结构

底部菜单采用 5 个主入口：

1. 今日
2. 运动
3. 项目
4. 作业
5. 素材

成就和导出不单独占底部菜单。成就可作为“今日”和“素材”中的模块；导出放在“素材”页顶部或底部的明确入口。

## 页面设计

### 今日页

定位：每天使用的起点，不是打卡表，而是“今日任务局”。

内容：

- 今日日期和一句任务引导，例如“今天去哪里探索？”
- 今日三件事：
  - 运动到了
  - 说出来了
  - 留痕了
- 快速开始入口：
  - 运动记录
  - PBL 任务
  - 书面练习
  - 今日留痕
- 今日推荐任务：
  - 从任务卡库中按类型展示 1-3 个可选任务。
  - 允许用户跳过推荐，直接进入任意任务包。
- 今日记录摘要：
  - 运动几分钟
  - 作业几项
  - PBL 任务几项
  - 素材几条
- 成就提示：
  - 今日星星
  - 连续记录天数
  - 当前称号

### 运动页

定位：运动日志，支持孩子和妈妈一起记录，但第一版以孩子暑假运动为主。

记录字段：

- 日期
- 运动类型：快走、游泳、球类、攀爬/平衡、散步、其他
- 时长
- 地点
- 是否和妈妈一起运动
- 状态：轻松、刚刚好、有点累
- 备注

展示：

- 今日运动汇总。
- 本周运动完成情况。
- 运动类型分布。
- 与教案目标对照：
  - 每天两段活动。
  - 合计 90 分钟以上。
  - 每周游泳 2-3 次。
  - 每周球类/跑跳 2 次。
  - 每周攀爬/平衡 2 次。

### 项目页

定位：PBL 任务地图。8 个主题包可以任意穿插，不按周次强制锁定。

主题包来自教案：

1. 我是旅行小队长
2. 城市职业观察员
3. 自然调查员
4. 苏州园林小建筑师
5. 小小店长
6. 杭州/良渚文明探索
7. 交通工程师
8. 暑假成果展小馆长

每个任务包包含：

- 目标
- 重点能力
- 任务列表
- 妈妈提问
- 成果目标
- 当前进度

每个 PBL 任务采用四步引导：

1. 准备：今天需要带什么、去哪里、观察什么。
2. 观察/体验：看到什么、听到什么、做了什么。
3. 表达：孩子讲了什么、画了什么、搭了什么。
4. 成果：照片、职业卡、路线图、自然观察页、作品说明等。

任务状态：

- 未开始
- 进行中
- 已完成
- 已产出成果

### 作业页

定位：书面练习记录。它与 PBL 分开，避免把项目制学习变成练习册管理。

分类：

- 数学
- 拼音
- 认字
- 其他

记录字段：

- 日期
- 分类
- 内容名称
- 数量或页数
- 用时
- 难度：简单、合适、偏难
- 孩子状态：主动、配合、抗拒
- 备注

展示：

- 今日作业完成情况。
- 本周各分类分布。
- 最近偏难或抗拒的项目，方便用户调整量。

### 素材页

定位：作品盒子和导出中心。

素材类型：

- 照片
- 孩子原话
- 妈妈备注
- 职业卡
- 路线图
- 自然观察页
- 积木/搭建作品
- 假商店/古人生活展/花园作品
- 视频讲解记录

记录字段：

- 日期
- 关联任务包
- 关联任务
- 素材类型
- 标题
- 内容文本
- 图片文件
- 地点
- 标签

第一版图片处理：

- 支持上传或选择图片并在本地浏览器保存。
- 如果受浏览器存储限制影响，可先保存图片预览和文件名，并在导出清单中列出。
- 不要求第一版完成跨设备云端图片管理。

导出：

- Markdown 作品册草稿。
- 素材清单 Markdown。
- JSON 数据备份。

Markdown 作品册结构：

- 封面：《泽一城市任务局》
- 暑假总览
- 今日记录精选
- 8 个主题包章节
- 职业卡汇总
- 路线图汇总
- 自然观察页
- 作品展示
- 小馆长讲解提纲

## 成就体系

成就要鼓励持续探索，不制造压力。

积分与星星：

- 运动记录：1 星。
- 完成一次 PBL 任务步骤：1 星。
- 添加一条素材：1 星。
- 完成一次书面作业记录：1 星。
- 今日三件事都完成：额外 2 星。

称号：

- 城市小队员：累计 10 星。
- 路线小队长：完成 2 条路线或交通相关记录。
- 职业观察员：完成 3 张职业卡。
- 自然调查员：完成 3 条自然观察。
- 小小店长：完成一次买卖游戏记录。
- 小馆长：完成作品册导出。

完成度：

- 暑假总完成度按成果目标计算，不按每天全勤计算。
- 核心成果目标：
  - 职业卡 8 张
  - 旅行路线图 4 张
  - 任务照片 8 张
  - 自然观察页 5 张
  - 积木/展览类作品 3 个
  - 小馆长讲解视频记录 1 段
  - 妈妈运动记录 8 周

## 视觉风格

整体方向：城市地图冒险 + 卡通手绘研学 App。

原则：

- 首页不能像表格打卡文件。
- 使用底部菜单做清晰切换。
- 每个分类内部采用符合该分类的常规结构。
- 视觉有探索、地图、任务站点、路线、贴纸感。
- 记录入口要明显，不能因为装饰影响操作。

建议视觉元素：

- 清爽蓝绿作为基础。
- 番茄红、阳光黄、草绿色作为任务色。
- 地图路线、站点圆点、任务卡片、贴纸徽章。
- 轻微手绘描边，但保持按钮和文字清楚。

## 验收标准

实现完成后至少验证：

1. 手机尺寸下底部菜单可正常切换。
2. 今日页可以快速新增运动、作业、PBL 留痕。
3. 项目页能查看 8 个任务包，并进入任务步骤。
4. 运动页能新增记录并显示本周汇总。
5. 作业页能按数学、拼音、认字记录。
6. 素材页能新增孩子原话、妈妈备注和图片类素材。
7. 成就星星能根据记录更新。
8. 能导出 Markdown 作品册草稿。
9. 能导出 JSON 备份。
10. 页面风格接近城市研学手册，而不是普通打卡表。

## 实现建议

为了明天可用，建议第一版使用单页前端应用：

- React + Vite。
- 本地 IndexedDB 或 localStorage。
- 无后端。
- 可部署为本地网页，也可后续部署成静态站点。

第一版重点是记录链路和任务包数据。PDF、云同步、微信小程序迁移放到第二阶段。
